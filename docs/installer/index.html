1 · Prerequisites

Alexa-side configuration (manual, cannot be automated)

The wizard generates all AWS resources and the PC agent, but these two Alexa-console artifacts must be created by hand:

  1. Login with Amazon security profile — required for account linking (create here; details in setup guide Step 2).
  2. Create a Smart Home skill ("Provision your own") and enable its Send Alexa Events permission — the Alexa Client Id / Client Secret shown there go into Step 3 of this wizard. Alexa Developer Console

Full background: docs/setup-guide.md. The wizard replaces its Steps 1, 3 and 6.

4 · Install the PC agent

  
Run the matching one-liner on the target PC. Pick a device below to have ID/secret filled in.

  

    
  

  

    
  

  
The installer registers a boot-persistent task (Windows: SYSTEM scheduled task; Linux: systemd service), runs WoL pre-flight checks, tests bridge connectivity, and supports uninstall/repair/status later.


  

    
Windows — elevated PowerShell 

    

  

  

    
Linux — bash (root) 

    

  


  
Manage later (from the repo checkout)

  
# Windows
.\install-agent.ps1 -TestConnection          # one-off poll against the bridge
.\install-agent.ps1 -Status -Live            # task state + live poll
.\install-agent.ps1 -Repair                  # re-register task from saved config
.\install-agent.ps1 -Uninstall -Purge        # remove everything

# Linux
./install-agent.sh status --live
./install-agent.sh repair
./install-agent.sh uninstall --purge
